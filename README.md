Nom du jeu : Save Castle

Parties réussis : 

                  - Les animations du joueur : Idle, Walk/Run, Jump, Attack et Dead 
                  
                  -Les animations de l'ennemi : Idle, Fly et Attack
                  
                  - Création de nouveaux scènes : Play, GameOver, PlayAgain...
                  
                  - Déplacement des ennemis
                  
                  - Mettre des sons dans les animations ou autres
                  
                  - Mettre un son ambiant
                  
                  - Collecte des potions
                  
                  - Animation de la porte : La porte s'ouvre, le joueur disparaît et le jeu se termine

Parties non réussis :

                  - La partie UI Heart : Pour re-remplir les sprites (coeurs) quand le joueur collecte les potions. Toutefois, selon la console, le joueur collecte bien les potions.
                  
                  - Le lac acide : Oui, quand le joueur plonge dans l'eau, il meurt, mais il n'y a pas d'effets sur les heart sprites.

Parties non faites :

                 - Quand le joueur attaque tous les ennemis, comptant le dragon, la princesse se libère de la cage.
